# Ecobazar

Учебный интернет-магазин свежих продуктов на чистом HTML, CSS и JavaScript.  
Без фреймворков и сборщиков — только ванильный стек и ES-модули.


## Что уже работает

- Добавление товаров в корзину
- Пересчёт общего количества и суммы
- Изменение количества товара (кнопки «+» и «−»)
- Удаление товара при уменьшении количества до нуля
- Сохранение корзины в `localStorage` — не пропадает при перезагрузке страницы
- Модальные окна входа и регистрации
- Слайдер отзывов на Swiper
- Адаптивная вёрстка (базовые брейкпоинты под планшет и телефон)


## Технологии

- **HTML5**
- **CSS3** — без препроцессоров
- **JavaScript** — ES-модули (`import` / `export`)
- **[Swiper](https://swiperjs.com/)** — слайдер отзывов
- **`localStorage`** — хранение корзины между сессиями
